Privacy Policy

Last updated: October 29, 2026

Purpose

Sushi Restic Backup is a personal backup utility that uses Google Drive as remote storage for encrypted Restic backup repositories.

Google Drive Access

The application accesses Google Drive to create, upload, retrieve and manage its backup files.

Data Storage and Security

Backup data is encrypted by Restic before upload. OAuth credentials are stored locally on the backup host and are not exposed by this website. Google Drive acts as the storage provider.

Data Sharing

The application does not sell user data or use Google Drive information for advertising. This website does not collect visitor data through analytics or tracking scripts.

Access Revocation

Google Account permissions can be revoked through Google Account security settings.
